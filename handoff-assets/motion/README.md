# 病区人物素材

本目录保存病区人物的原始图集、生成提示词与装配映射。正式站点读取 `public/art/` 中的透明 WebP 图集。

## 覆盖范围

- 15 套成人患者外观：卧床、床旁近景、头像、四向步态，以及坐起、床沿落脚、起身和回床姿态共享外观编号。
- 唐济、姜蓉、李恂、周乔、叶茗：四向四拍步态、记录和交谈动作。
- 护士推车、保洁拖把与桶：四向移动和停留工作；工具随同本人。
- 三组未注明性别的陪护外观：成人、少年和年长者的四向站立与短眨眼。场景中的到场人数由实际照护需要与事件控制。

儿童、婴儿与孕期患者沿用相应的卧床和近景素材。现有独自散步路线不适用于需要陪同活动的患者。

## 文件与映射

`sources.json` 定义每张原图的行列、人物编号及帧映射；`prompts.json` 保存内置 ImageGen 的生成及修改提示词；`base/` 保存静态图集底本，防止重新装配时累积覆盖旧图。

人物源图采用纯洋红背景，导入时只移除背景色及其边缘混色，保留白衣、浅色被褥和人物轮廓。各帧按头部中心与脚底锚点对齐，不按伸出的手臂或推车外缘重新居中。

| 正式图集 | 单格 | 行与列 |
| --- | --- | --- |
| patient-motion-atlas.webp | 128×128 | 28 行 × 16 列；使用原始成人外观编号 |
| patient-transitions-atlas.webp | 128×128 | 28 行 × 4 列；未使用行透明 |
| staff-motion-atlas.webp | 128×128 | 5 行 × 16 列 |
| staff-actions-atlas.webp | 192×128 | 5 行 × 8 列 |
| ward-haul-atlas.webp | 256×128 | 2 行 × 16 列 |
| ward-care-atlas.webp | 256×128 | 2 行 × 8 列 |
| companion-walk-atlas.webp | 128×128 | 3 行 × 8 列；站立及眨眼 |

方向按前、左、右、后排列。普通人物脚底锚点为 `(64,122)`；192 像素宽工作帧为 `(96,122)`；256 像素宽工具帧为 `(128,122)`。正式地图按 72/128 的比例绘制。

## 重新装配与检查

使用 Node.js 22 与 Sharp：

```sh
TYCHE_SHARP_PATH=/path/to/sharp node scripts/prepare-motion.mjs
npm run build
npm run test:e2e -- --workers=1
```

装配结果与 SHA-256 写入 `output/motion/atlas-report.json`。浏览器回归会实际解码 432 个已使用的动作帧，检查空帧、裁切边缘、洋红残留与卧床首帧的一致性。

开发服务器中的 `tests/visual/ward.html` 可检查不同年龄、床位和活动状态。该入口不进入正式构建。
