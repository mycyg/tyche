# Tyche 人物、结局与音乐素材

素材未接入游戏，接入时不覆盖原图。新增图像由内置 image_gen 生成，保留提示词和源图；透明处理与图集切分沿用已获授权的本地抠图流程。新增图像、音乐及制作脚本按项目 MIT 许可开放。

主故事使用 [`dark-expansion/README.md`](dark-expansion/README.md)：40 个以名著命名的主结局及其独立 CG，另有 160 帧家庭／冲突／谋生角色与 30 个表情画像。与下方病区图集合计 328 帧场景角色。用词规范见 [`copy-guidelines.md`](dark-expansion/source/copy-guidelines.md)，已改文案的配音由接手者补录。

## 人物图集

使用 `art/*-atlas.webp` 或同名 PNG，不使用带底色的原始图。`art/manifest.json` 提供每帧矩形和脚底锚点。

| 图集 | 行数／帧数 | 从上到下的人物 |
| --- | --- | --- |
| staff-walk-atlas | 5／40 | 唐济、姜蓉、李恂、周乔、叶茗 |
| ward-life-walk-atlas | 6／48 | 普通护士、男护工、女保洁、青年男家属、中年女家属、老年男家属 |
| patient-walk-atlas | 6／48 | 成年男患者、成年女患者、老年男患者、老年女患者、儿童患者、孕妇 |
| ward-actions-atlas | 4／32 | 姜蓉工作、男保洁工作、女家属陪护／录音、男家属陪护／录音 |

前三张图集均为每行一个人物，每两个相邻格组成两帧动作：第 1–2 列向下，第 3–4 列向左，第 5–6 列向右，第 7–8 列向上。格子 128×128，脚底锚点 (64,122)，儿童按较小体型保留。可先按 180–220 毫秒一帧接入，角色停止时使用已有待机图集。

工作图集每格 192×128，锚点 (96,122)。每行依次四组动作，每组两帧：

1. 姜蓉：向右推车、向左推车、查阅夹板、听诊。
2. 男保洁：向右拖地、向左拖地、拧拖把、收垃圾袋。
3. 女家属：坐候、举手机录音、递水、说话。
4. 男家属：坐候、举手机录音、递餐袋、指着说话。

工作表的男保洁、短红棕发女家属是独立外观变体，不要和行走表里的女保洁、棕发女家属混成同一人。推车、坐凳等道具已经画在工作帧内，场景不要重复放一份。卧床患者仍用 `public/art/bed-patients.webp` 与扩展卧床图；只有剧情允许下床者才使用行走图。

地图移动、碰撞、交互跟随、任务标记和昼夜人流由后续开发接入。图集存在不代表这些行为已经实现。

## 结局图片

`dark-expansion/endings/` 提供 END-01—END-40 新主结局 CG，应作为主结局接入来源。下方 `endings/` 的 X01–X41 保留供旧运行时与附件迁移查阅，不与 END 编号按数字对应。完整场景和生成提示词分别见两个目录的 `manifest.json`。

图片采用暗色像素质感与二次元人物，不含标题、正文、边框或 UI。结局页采用上图下文，正文由游戏排版，不叠在人物脸部。按结局 ID 或 `sourceId` 关联；主结局与附件分别取图，不改变现有结局判定。图片按需加载，勿在开局加载全套。

## 新增音乐

| 文件名 | 场景 | 时长 |
| --- | --- | ---: |
| ward-rounds | 忙碌病区与白天巡床 | 40.0 秒 |
| family-call | 家庭来电与筹款 | 58.2 秒 |
| research-afterhours | 办公室与科研 | 42.7 秒 |
| complaint-pressure | 录音、投诉与争执 | 33.1 秒 |

四段均为原创程序作曲，无人声、无商业音乐采样。每段附 32 kHz 双声道 WAV 母带、OGG 与 128 kbps MP3。优先使用 OGG 循环，MP3 作为兼容格式，WAV 不放进 Pages。循环区间、节拍和采样数见 `music/manifest.json`。

音乐的解码、时长及首尾接点已检查；与对白的实际混音还需在游戏内听。建议沿用现有对白期间压低音乐的逻辑，不同时叠播两首完整 BGM。

## 制作来源

- 图片提示词：`source/image-prompts.json`；角色参考：`public/art/npc-idle.webp`。
- 结局图片：内置 image_gen 独立生成；每张完整提示词见 `endings/manifest.json`，分组清单保留在同目录。
- 图集打包：`source/prepare_atlases.mjs`，依赖 sharp；可用 `TYCHE_SHARP_PATH` 指定依赖位置。
- 音乐作曲：`source/compose_additions.py`，复用仓库 `scripts/compose-score.py` 的合成音色；依赖 numpy、soundfile、imageio-ffmpeg。
- 原始生成 PNG 与背景编辑结果一并保留，接入使用带 `-atlas` 的最终图集。
