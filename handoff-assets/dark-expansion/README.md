# Tyche · 故事与美术素材

本包包含 40 个主结局的正文与 CG、160 帧场景角色图、30 张人物表情画像。素材采用原创暗色像素 JRPG 场景与二次元角色设计，按项目 MIT 许可提供。素材存在不代表已接入游戏。

## 结局

- `content/ending-catalog.json`：END-01 至 END-40 的书名、作者与场景。
- `content/ending-prose.json`：40 篇完整结局正文。`paragraphs` 是显示正文；`speech` 只标记其中已有的直接引语，不能再追加显示或重复播放。
- `endings/manifest.json`：40 张 CG 的完整提示词、标题、作者、尺寸和路径。
- `endings/END-xx.webp`：发布图，共约 7.40 MB；对应 PNG 保留源图，尺寸均为 1672×941。
- `qa/endings-1.png` 至 `qa/endings-4.png`：图片总览，仅用于开发查阅，不是玩家结局页面。

END-40《平凡的世界》是唯一真结局。其余结局包含服刑、伤医死亡或失能、持续精神症状、自杀身后、家庭破裂、债务、艰难谋生和依靠伤害他人保住职位的后果。图内不含书名和正文，采用上图下文排版。

这些 END 编号属于新主结局目录，不与旧 X01—X41 或事件 E 编号按数字直接对应。旧 X 图集保留，不作为新主结局的首选映射。自杀结局只表现遗物与留下的人；独立的“致玩家”卡在故事之后呈现。

CG 中的出场家人须与当局存活、关系和到场记录相容。END-20 固定为父亲去世场景；END-38 固定为无罪判决；END-39包含治疗和欠款前史。END-18使用女伴侣离场形象；男伴侣设置应使用合适裁切及对应画像，不把同一女性角色改称男性。具体衔接记录见 `content/copy-audit-story.md`。

场景使用 `characters/*-atlas.webp`，不要使用有棋盘格的原始表。帧矩形、脚底锚点、角色 ID、原图裁切坐标和已执行的水平翻转均在 `characters/manifest.json`。

行走格 128×128，脚底锚点 `[64,122]`；工作格 192×128，锚点 `[96,122]`。行走列顺序为面朝下两帧、左两帧、右两帧、背面两帧。工作每种动作两帧，具体列序见对应生成清单和 `source/art-briefs.json`。家庭原图第 3 列的错误朝向已在图集切分时翻转。

`family-portraits.webp` 为 4×3，`conflict-portraits.webp` 和 `livelihood-portraits.webp` 各为 3×3。画像列序为疲惫平静、争论、退缩难过，共 30 张；采用深青实底，按 manifest 的原生矩形取图。

机械处理脚本为 `source/prepare-atlases.mjs`。原有透明通道保留；有浅棋盘底的源表采用获准的边界连通抠图。裁切按角色间空隙调整，避免伸手动作被等格边界截断。`qa/*-walk.png`、`qa/*-actions.png` 是铺灰底的透明与裁切检查图。

已有 `../art/` 的 168 帧病区素材继续使用，两包合计 328 帧场景角色素材。卧床患者仍用游戏 `public/art/` 中已有患者素材，不能以行走表替换床上的患者。

## 接入注意

- 新动作图集已完成裁切，不等于 NPC 路线已经实现。姓名、任务标记、交互范围和朝向应跟着人物走；对话时暂停，结束后继续工作。
- 家庭与谋生行走表的部分两帧步态差异较小，适合基础走动；不要把素材存在标记为所有动作已通过游戏内验收。
- 工厂揉腕的两帧没有帽子，作为取帽休息姿态使用；不要与戴帽行走连续切换成闪帽。
- 工作表与行走表的头身比例略有区别，已统一脚底和占格；接入时按同一角色校对缩放。
- 固定场景、换床、出院、死亡、离岗和家庭离开应同步改变人物状态。不要让床边家属已离开，录音热点却仍留在那里。
- 结局和新图集按需加载。PNG 源图、总览图、生成记录和母带无需进入网页发布包。

## 文案与声音

`source/copy-guidelines.md` 是本项目用词规范。`content/copy-audit-*.md` 分别记录故事、事件、患者、完整病例及界面运行时的审读范围。文案处理不删除病例、事件或分支，不改判定条件和医学数值。

本包没有新增录音。旧音频仍属于旧台词，不能视作新文案配音完成。接手者在文案接入后重新采集全部当前台词，再补录新增和已改动的语句；新 40 结局及“致玩家”正文必须加入采集范围。远端制作步骤位于本地 Claude 交接文件，不在本仓库保存机器连接资料。
