# 声音与角色短语音

角色每次互动播放一句固定短语音，每组保留三句并依次轮换。它们是角色的简短回应，不是屏幕对白的逐字配音。旁白、病历、规则、收藏记录和结局说明均保持静音。

## 角色与播放

十二组角色为程医生、唐济、姜蓉、李恂、周乔、叶茗、父亲、母亲、医保稽核员、男性患者、女性患者和患者家属。角色表与固定台词在 `src/shared/character-voices.ts`。

- 每次互动只选播当前角色的一句，不连续播放整组三句。
- 同一个角色的录音共用一份原创合成参考音频，保持音色一致。
- “重听”播放刚才那句，不切换到下一句。
- 关闭对话、切换交互或进入后台会停止旧语音。未完成的网络请求不能在新角色开口后插播。
- 录音缺失、角色不符或网络失败时保持安静，不替换成旁白，不拼接零碎录音，也不启用系统朗读。
- 背景音乐、角色短语音与操作音效分别开关和调节音量。语音播放时音乐音量降至设定的 26%，结束后恢复。

新语音包共 454,464 字节。旧全文录音保留为源文件，不进入网页发布包。浏览器仅按需加载静态 MP3，不下载模型、不连接推理服务。音频通过首次点击或按键解锁。文字和所有操作不依赖声音。

## 制作与核对

制作流程参考 NovelCast 的固定角色声线与转写核对方式。Qwen3-TTS VoiceDesign 根据人物表演描述生成原创参考声线；Qwen3-TTS Base 以这份合成参考录制三句短语音。两阶段使用 CUDA，在 RTX 3090 上运行，不使用真实人物的声音样本。

`scripts/render-character-voice-cuda.py` 读取模型校验清单与角色表。模型文件须通过 SHA-256 核对；生成记录保留模型修订、参考音频校验值、随机种子、角色、台词、时长与 MP3 校验值。短语音为 24 kHz、单声道、80 kbps MP3，统一响度。

`public/audio/character-voice/manifest.json` 为制作与质检记录；`index.json` 为播放索引。36 句录音经本地 Qwen3-ASR-1.7B-8bit 转写，去除标点后均与目标台词一致。索引只接纳角色和文本一致、音频文件校验通过且转写匹配的短语音。请求地址包含录音内容版本，更新录音时不会继续命中同名旧文件。

```bash
npm run audio:collect
npm run audio:check
npm run typecheck
npm test
npm run build
npm run test:e2e
```

`audio:collect` 在本地 `output/character-voice/` 导出角色表和三句台词；该目录不进入版本库。`audio:check` 核对三十六句录音、对应角色、转写状态、长度和文件内容，再生成播放索引。

## 音乐与音效

十二个配乐场景包括标题、日间病区、夜班、压力、精神失真、调查、两种结局，以及查房、家人电话、科研加班和投诉压力。MP3 随站点发布；后四首另提供 Ogg，并按已记录的循环点衔接。切换场景使用交叉淡入淡出。

按键、翻页和掷骰提示音由浏览器合成。关闭角色短语音不影响背景音乐与操作音效的独立设置。
