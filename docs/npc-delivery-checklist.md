# 场景角色与动作 · 交付验收清单

先完成当前修复与可玩流程，再实施本清单。各项完成后用一轮场景检查记录问题，轮后合并修复同类问题；通过项不重复打磨。

## 1. 病区有生活人物

- [ ] 玩家不移动、不点菜单时，场景仍持续运行人物路线与工作动作；各人物错峰活动，不能全场只剩呼吸、眨眼或静态精灵平移。
- [ ] 增加非任务 NPC：巡床护士、推车护士或护工、清洁人员、候诊及送物家属。按区域安排，不让所有人聚在护理站。
- [ ] 病房有床旁陪护：坐候、照料、与患者说话；走廊有往返的人。无需每个人都能接任务。
- [ ] 移动与停留交替，人物错开出发；白天与夜班的人流有区别。玩家停下时，病区仍有人做事。
- [ ] 路线避开墙、病床及柜台；不堵门、不挡患者与操作目标。没有任务的人不挂任务标记。

## 2. 交互角色在场景中行动

- [ ] 护士巡床、医生在办公室与病区间走动，其他角色按身份停留或行动；不要求每个人一直走。
- [ ] 行走有朝向与步行动画，停下有待机或工作动作，不能用整张静态图平移冒充步行。
- [ ] 姓名、任务提示、点击范围和接近交互位置跟随角色；对话时停留并面向玩家，结束后继续原活动。
- [ ] 玩家能找到需要交互的人；不能因为 NPC 走远而错失必做事项。移动不消耗行动值，也不改变事件检定。
- [ ] 家属录音、投诉、床旁沟通由对应人物在合适位置呈现；病人出院、转床后，患者和陪护同步离场或换位。
- [ ] 家庭人物按来院、等待、争执、分离与搬离状态进出；关系破裂影响来访和互动，不只是数值变化。伴侣性别与称谓按设置匹配。
- [ ] 安保和调查人员按事件到场，有巡视、对讲、询问、收材料或护送动作；未发生相应事件时不把玩家当作已被调查。

## 3. 素材与场景对应

- [ ] 按角色类型建立素材表：主角、医护、其他交互角色、背景人物、患者、家属。列明待机、行走、坐卧与实际剧情动作。
- [ ] 覆盖成年、老年、儿童、婴儿、孕妇等患者类型及不同家属外观；场景精灵、床旁近景与对话画像保持同一身份。
- [ ] 卧床患者留在对应床位；适合下床的患者可坐起或走动，不让所有病人套用同一活动模式。
- [ ] 推车、清扫、陪护、录音等已经出现在玩法中的动作有对应人物与道具素材；不为没有使用的动作制作空图集。
- [ ] 检查透明背景、脚底位置、像素比例、前后遮挡与行走方向；不穿床、不浮空，不让前景家具盖错人物。
- [ ] 桌面、手机横屏和竖屏均可看清患者与陪护；状态栏不挡床位。减少动态效果后仍能找到并操作交互角色。

素材可以按外观类型共享、换色或组合，不要求 251 位患者各画一套；年龄、体态与角色身份不能错配。

## 场景检查记录

每轮记录构建、区域、角色类型、屏幕方向和问题；重点走病房、护理站、走廊、急救／留观区。发现漏人、错图、交互位置脱节或遮挡错误后，按同一角色类型或渲染规则统一修复。结果记入 [游玩问题台账](playtest-ledger.md)。

观察至少一个完整活动周期：玩家站定，跟随任务 NPC，进行一次床旁交谈或录音，再检查一次出院／转床／离场。人物能走到目标、工作后离开，标记和交互范围跟随。静态截图和只有待机帧的录屏不能证明持续活动已完成。
