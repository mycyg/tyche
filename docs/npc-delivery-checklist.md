# 场景角色与动作 · 交付验收清单

先完成当前修复与可玩流程，再实施本清单。各项完成后用一轮场景检查记录问题，轮后合并修复同类问题；通过项不重复打磨。

实现位于 `src/world/npc-art.ts`（图集矩形与锚点）、`src/world/npc-schedule.ts`（人物、路线与到场条件）、`src/world/npc-runtime.ts`（状态推进）与 `src/world/WorldStage.tsx`（绘制、遮挡与交互跟随）。

## 1. 病区有生活人物

- [x] 玩家不移动、不点菜单时，场景仍持续运行人物路线与工作动作；各人物错峰活动，不能全场只剩呼吸、眨眼或静态精灵平移。
- [x] 增加非任务 NPC：巡床护士、推车护士或护工、清洁人员、候诊及送物家属。按区域安排，不让所有人聚在护理站。
- [x] 病房有床旁陪护：坐候、照料、与患者说话；走廊有往返的人。无需每个人都能接任务。
- [x] 移动与停留交替，人物错开出发；白天与夜班的人流有区别。玩家停下时，病区仍有人做事。
- [x] 路线避开墙、病床及柜台；不堵门、不挡患者与操作目标。没有任务的人不挂任务标记。

现状：白班同时在场 13 至 24 人（随住院人数与已发生事件变化），夜班减为 9 至 15 人。出发时间按 0.6 至 10.4 秒错开，停留时长 1.2 至 12 秒。所有停靠点与相邻停靠点之间的寻路结果逐点通过 `walkable`；仿真 150 秒内没有人物进入 12 张病床的矩形，也没有人物离开地面。停靠点与四处病房门口保持 12 像素以上距离。背景人物不进入 `worldTargets`，因此不绘制任务标记，也不能被点击。

## 2. 交互角色在场景中行动

- [x] 护士巡床、医生在办公室与病区间走动，其他角色按身份停留或行动；不要求每个人一直走。
- [x] 行走有朝向与步行动画，停下有待机或工作动作，不能用整张静态图平移冒充步行。
- [x] 姓名、任务提示、点击范围和接近交互位置跟随角色；对话时停留并面向玩家，结束后继续原活动。
- [x] 玩家能找到需要交互的人；不能因为 NPC 走远而错失必做事项。移动不消耗行动值，也不改变事件检定。
- [x] 家属录音、投诉、床旁沟通由对应人物在合适位置呈现；病人出院、转床后，患者和陪护同步离场或换位。
- [ ] 家庭人物按来院、等待、争执、分离与搬离状态进出；关系破裂影响来访和互动，不只是数值变化。伴侣称谓与形象按设置匹配。
- [x] 安保和调查人员按事件到场，有巡视、对讲、询问、收材料或护送动作；未发生相应事件时不把玩家当作已被调查。

现状：

- 唐济在主任办公室、护理站与 A 病房之间移动；姜蓉从护理站推车到床旁，做听诊与查阅夹板，再回站记录；李恂在值班室、走廊、护理站与 C 病房之间移动；周乔在科研室桌前与走廊之间移动；叶茗在走廊四点之间移动。夜班改为各自的短路线，五人都留在场内。
- 行走使用四方向两帧，195 毫秒一帧；停留使用工作帧或该方向的第一帧，340 毫秒一帧。推车与拖地使用工作图集的左右两组，不使用行走帧。
- `Target` 增加 `npc` 字段，姓名标签、任务标记、点击判定、寻路终点与接近判定全部读取人物当前坐标。玩家点选待办后每 260 毫秒重新计算路线，终点偏离超过 22 像素时重算。
- 交互开始时人物停止并转向玩家，`props.frozen` 与 `props.dialogueOpen` 都为假且已过 400 毫秒后恢复路线。人物移动只写入 `WorldStage` 的局部状态，不进入 `Run`。
- 陪护与冲突家属由 `worldOccupants` 与 `r.patients` 推导，患者出院、转床或不再在院时定义随之消失，录音热点不会留在原位。
- 家庭线未完成项：伴侣性别目前没有设置项。默认使用女伴侣行，读到 `伴侣-男` 时换用男伴侣行；见下方跨文件需求。搬离场景使用 `家庭-卖车` 或 `家庭-降级` 作为替代条件，专用的分手与搬离事实尚未在事件层产出。

## 3. 素材与场景对应

- [x] 按角色类型建立素材表：主角、医护、其他交互角色、背景人物、患者、家属。列明待机、行走、坐卧与实际剧情动作。
- [x] 覆盖成年、老年、儿童、婴儿、孕妇等患者类型及不同家属外观；场景精灵、床旁近景与对话画像保持同一身份。
- [x] 卧床患者留在对应床位；适合下床的患者可坐起或走动，不让所有病人套用同一活动模式。
- [x] 推车、清扫、陪护、录音等已经出现在玩法中的动作有对应人物与道具素材；不为没有使用的动作制作空图集。
- [x] 检查透明背景、脚底位置、像素比例、前后遮挡与行走方向；不穿床、不浮空，不让前景家具盖错人物。
- [x] 桌面、手机横屏和竖屏均可看清患者与陪护；状态栏不挡床位。减少动态效果后仍能找到并操作交互角色。
