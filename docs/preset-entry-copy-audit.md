# 预设接诊首步与沟通角色核查

## 内容范围

208 个预设均有独立首步反馈，记录在 `src/content/patients/entry-copy.ts`。反馈区分病史、实际查体、读取既有资料和会诊，不再统一写成“重新询问病史”。首步操作分类为问史 79、查阅或观察 41、查体 86、会诊 1、完整查体 1。

判读以病例来源的公开资料、原动作范围及原检定要求为准。相同患者模板没有代替真实的年龄、陪同关系、孕周或就诊场景。未取得的孕周、检验数值、影像和病因不会补写为正常或确诊。

## 检定与反馈

| 范围 | 可见内容 | 消费者与约束 |
|---|---|---|
| 12 个明确查体入口 | 只给对应成功体征；失败保留入院已知资料 | `applyEntryEvidence` 写入原察觉难度；`optionCosts` 与实际选择确认使用该检定 |
| 38 个明确病史入口 | 只给所问范围内的原始回答 | 原问诊难度；失败不提供隐瞒史，成功也不自动产生未做的检验 |
| 其中 5 个私下问诊入口 | 陪同者回避后由本人回答 | 显式病例白名单；免除此动作的陪同干扰，不免其他隐瞒、语言等修正 |
| C-068 床旁血糖 | 原文允许直接取得的 1.9 mmol/L | 不附带未问到的降糖药史 |
| 未成年人通用沟通 | 实际母亲、父亲、祖辈或其他陪同者复述安排 | 监护人权限与普通陪诊关系分开；可表达意见的患儿仍参与说明 |
| 婴幼儿拒检及欠费沟通 | 向实际陪同者说明，核实权限或紧急备案 | 拒检门禁不执行原检查、不先收费、不编造检查结果 |

C-091 的首步是眼震、共济和步态检查，使用原察觉难度 13。成功显示垂直及随注视方向改变的眼震、指鼻不准和不能站立；不声称已经完成头脉冲试验或脑血管影像。

C-134 的首步使用原问诊难度 11。成功时母亲说明出生第 2 天起黄、未按产院建议复查；失败不提前给出这两项病史。21 mg/dL 与母子血型留在相应实际检查之后。

所有首步保留原行动、时间、费用、体力、伤害与分支去向。新增检定的失败仍消耗原有体力。问到一项病史不等于整份底牌已经查明，也不等于已经完成治疗。

## 保存与恢复

`instantiatePreset` 生成具体患者的文字；`presetCard` 与 `refreshPresetEntryCopy` 投影当前未执行卡片。病例原文、已发生的日志、费用和骰子均不因刷新文字被重写。已经展示的待确认检定保留原选项、难度和骰子，不事后替换为新检定。

## 证据与边界

- `entry-copy.test.ts`：208 首步操作及实际兼容实例；源难度核对；成功与失败信息边界；实际引擎反馈、扣体力和旧待确认骰。
- `participant-copy.test.ts`：全部可兼容未成年人场景的通用沟通；母亲、父亲、祖辈区分；成年人的决定权不因精神病史或认知病史标签被直接替换；婴儿的实际沟通与拒检门禁。
- `generation.test.ts`：原种子顺序和抽取算法，共 45,889 次实际抽取，覆盖 250 个实体和 208 个预设，每次核对完整情境兼容。按种子分段提交测试结果，未减少原采样上限或合法性断言。
- `content.test.ts`：全部预设节点、合法选项、分支终止与患者身份范围。

以上不是 208 病例的逐个真人试玩记录。中段新增病例的所有自然语言组合、所有来源中的问史与客观检查混合范围，以及角色在全部后续事件中的措辞仍需结合真实试玩核对。本报告不把首步覆盖、自动路径遍历或测试种子覆盖称为“全部文案无问题”。
