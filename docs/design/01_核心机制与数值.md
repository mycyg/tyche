# 01 · 核心机制与数值

本文件是全局规则、公式、默认值与调参范围的权威来源。单病例剂量、费用、耗时和单事件代价由对应内容条目承载，但须符合本文件的量级与规则；结局与支线使用的全局阈值须回到本文件定义。所有标【假设】的数值在实现后通过模拟与人工试玩定稿。

---

## 1. 一局的结构

- 一局 = 14 个回合（14 天）+ 第 15 天鉴定庭。
- 提前结束：体力第二次归零、SAN 首次归零自救失败或再次归零、情绪第二次归零、债务结局、被刑拘（药代线统方被查）、提桶跑路（任意结算页可选）。
- 夜班日：D3、D6、D9、D12、D14（五个夜班）。夜班日的白天流程照常，傍晚结算后进入夜班；夜班后一天（D4、D7、D10、D13）开局体力 = 上限 − 30。

### 1.1 一天的阶段

| 阶段 | 内容 | AP 消耗 | 备注 |
|---|---|---|---|
| 晨间交班 | 病区概况；可翻阅在床病历（每份 1 AP）；交班事件 | 0–3 | 翻阅是发现他组转入隐患的唯一途径 |
| 病区查房 | 病区容量 12 床，开局交接 5 名住院患者，其中 2 名稳定；每日新增床位见运行调参表。活跃患者逐人处置，稳定患者可以免费完成维持记录，也可主动深查 | 依患者状态与所选处置结算 | 满床患者进入留观区，不能占用同一床号；未排风险出院会保留后续回院与投诉链 |
| 门诊 | 当日 N 个病人：1 个焦点病例按完整步骤图推进，其余为单节点快诊；到期回响可占用快诊位，D12–D14 可成为第二焦点 | 焦点 3–8；每个快诊 0–1 | 焦点病例步骤数 4–8；快诊仍有三项实质选择，不是自动结算 |
| 傍晚结算 | 绩效到账、DIP 超支扣款、支线节拍、事件 | 0 | 可预支明日 AP |
| 夜班（夜班日） | 时间预算制，不用 AP；2–3 起急诊 + 1 起突发 | 0 | 见 §6 |
| 日终检定 | d20 抗压检定，失败则 debuff 三选一 | 0 | 见 §7 |

### 1.2 行动值 AP

| 项 | 值 |
|---|---|
| 每日基础 AP | 10【假设 8–12】 |
| 抑郁 ≥50 | 基础 −1 |
| 夜班后一天 | 基础 −2（夜猫子天赋免除） |
| 预支上限 | 4 AP／天，明日基础 AP 等额扣减 |
| 预支代价 | 每预支 1 AP：体力上限 −1、SAN 上限 −1、情绪上限 −1（本局永久） |
| 加班（AP=0 且仍有未处理病人） | 允许继续行动；每步体力 −5、三上限各 −2（本局永久）；加班状态下所有检定 −1 |
| 放弃处理（AP=0 时选「明天再说」） | 每个未处理病人 R 隐患 +10、D 隐患 +10；病人若为底牌，成为种子的概率 +30% |

设计意图：AP 不够时的三个选项（预支、加班、放弃）分别用明天的自己、自己的上限、隐藏的隐患付账。

跨日行动分为可用额度变化与实际待办。通勤、疲劳等减少次日可用额度，下限为零，不因此产生加班；完整休假不虚构上班通勤。已经约定的胃镜、心理咨询和病历更正核实属于实际待办，按原事件数值在约定日消耗行动，休假不自动取消，行动不足按既有透支规则处理。选项和排班表须提前列明约定日期、事项与行动数【跨日行动语义细化，未改变原事件数值】。

## 2. 四张状态表与上限

所有上限起始 100【假设】。上限只降不升（本局内），永久属性可提高开局上限（§11）。

| 睡眠（日终） | 恢复到上限；失眠 debuff 时恢复到上限 ×0.7 |
| 疲劳档 | 体力 <50：检定 −1，门诊每步耗时 +25%，化验回报 30% 概率显示为扫读版；体力 <30：检定 −2，扫读概率 60%，选项措辞被疲劳改写（顺序打乱、动词替换） |

咖啡与午睡在值班室作为个人补给使用。完整休假不开放常规临床工作和预支，不禁止无行动消耗的个人咖啡购买；杯数、个人费用、恢复上限和声望代价照常计算。午睡仍要求足够的当前行动值，不能借午睡本身透支【休假补给范围细化】。

预支或透支导致状态上限下降时，先将超过新上限的当前值裁切到新上限，再计本次体力消耗。满体力 100/100 透支 1 行动且操作自身不耗体力时，上限变为 98，再扣 5 体力，结束为 93/98。提示与流水应同时列上限变化、操作消耗和实际当前值变化，不把上限裁切当作没有发生的损失。

**体力归零（第一次）**：触发「身体失灵」事件三选一（内容见 13_事件库·归零事件）：晕倒在值班室（同事顶班，人情债 flag，声望 −5）／被家属拍到睡在护士站（视频上网，声望 −15，医务科通报）／给自己做了一张心电图（自身健康线开启，体力上限 −20）。事件后体力恢复到上限的 50%。
**体力归零（第二次）**：结局「身体」族（06）。

## 3. 声望与关系

- 声望 0–100，起始 50。来源：处置得当 +2、锦旗 +5、投诉 −5、通报 −10、医闹升级 −10、拒诊 −5、加班到深夜 +1（护士长看见）。
- 声望 ≥70：鉴定庭「医院保你」生效（立案 DC −2）；主任愿意签字担责的事件开启。声望 <20：医务科备案，任何投诉直接升级；「医院开除」尾声开启。
- 关系值：主任、护士长、同年住院医、家人，各 0–5，起始 2。关系 ≥4 给对应检定优势（说服主任／安抚家属／同事顶班／家人电话恢复情绪），≤1 给劣势。

#### 绩效病组权重补充【假设】

病例或预设写有明确绩效金额时优先使用。未写明时，处置得当绩效按原始病组预算的 5% 映射，四舍五入到十元，最低 ¥80、最高 ¥300。计算使用首次接诊的原始预算，追加预算、申诉、后续超期扣减不改变绩效权重。208 条预设与 20 个完整病例均采用此规则，并在病例预设库内容矩阵逐项列出金额。

处置一般为 ¥40；未完成或不符合发放条件的处置不发放。等级依据实际结局、损害与未解决风险，不依据选项名称。医保欠费患者实际同意必要检查后，门诊绩效按处置一般计，催缴另行处理。已完成夜诊仍按每起 ¥100 的独立标准结算。一次接诊只发放一次，读档、重听与重复打开结果页不重复收入。该映射为虚构游戏经济参数，不是现实医保或薪酬标准。

### 4.2 DIP／DRG 预算

每个病例预设带 `dip_group` 与 `budget_cny`。病例累计费用 = 检查 + 药物 + 会诊 + 住院日费。结算时 `超支额 = max(0, 费用 − 预算)`，**超支额 100% 从余额扣除**（她的要求；调参范围 50–100%）。不超支但漏了该做的检查 → R 隐患（写在步骤里）。

预设基础费用计入患者账单，不直接扣医生余额。住院病组按预算的60%估算整个预计住院期的基础费用，由住院结算按天摊入；门急诊病组按预算的8%计入本次接诊基础费用。检查、处置、会诊和复评选项另行累计，最终仅超预算部分进入医生自付。夜班接诊不等于住院：是否按住院计费以病组及实际收住状态为准，不能在夜诊时把全程账单一次性记成医生自付。

无费用的对话、查看材料和角色能力不会启动医保结账。B24 的附加扣款只针对取得该状态后新结算的超支，已经支付的部分不追溯加价；真正的账单更正按原实付金额退还，不能借此反复套取退款。收费预览、实际扣款、患者总账和扣款来源使用同一口径【结账语义细化，未改变扣款倍率】。

|---|---|
| 住院基础费用预算比例 | 60% |
| 门急诊基础费用预算比例 | 8% |

### 4.3 负债

- 余额不能显示为负数。首次出现无法支付的必付账单时，暂停结算并触发「资金断裂」：信用卡／贷款（缺口转为负债，现金压力 +20）、向家人求助（每局一次，最多 ¥5,000，家人关系 −2、情绪 −10）、出售可用资产（按事件给现金，同时关闭对应后续选项）、接受眼前的灰色收入（仅在相关支线已开启时出现，并写入对应风险 flag）。没有免费跳过。
- 之后再有支付缺口，仍由玩家在当前可用方案中选择；只有主动选择信用卡／贷款的缺口才转为负债。余额显示为 0，负债单列。
- 资产与灰色收入的来源【假设，2026-09-07 引擎接口】：事件把可变卖资产写成事实 `asset-offer:<资产名>:<金额>`，资金断裂页按该金额变卖并写入 `asset-sold:<资产名>`，事件据此关闭后续选项；没有事件资产时只能变卖一次规则表里的闲置设备（¥3,500）。灰色收入只在药代支线已开启、事件写入 `gray-income-offer:<金额>` 时出现，接受后写入 `gray-income-accepted` 与 `kickback-received`，进入统方／回扣结局判定。
- 提桶跑路在傍晚结算页与日终小结（掷骰前）可选，确认后进入 E-209「收拾东西」，两项选择都结束本局（X31／X32）。
- 利息：每回合 3%【假设 1–5%】，结算时计入负债。
- **债务结局触发**：连续两个结算日，当日利息均大于近期实际日均收入；或负债 > ¥50,000【假设 30,000–80,000】。近期收入取最近 7 个结算日实际工资与绩效的平均值，不足 7 日则按已有结算记录平均【偿债窗口假设】。休假日实际收入为零，但不会单独抹掉此前收入；工资尚未到账、借款、赠款和待退回款不计收入。没有应付利息时不累计未覆盖天数。
- 还款：结算时收入自动先还债。

### 4.4 现金压力（半隐藏，只在药代与家庭事件里显示为「你想到了钱」）

`现金压力 = clamp(0, 100, 负债/500 + 家庭事件压力 + 近三日扣款/200)`，家庭事件压力：车祸 ICU +40（每日 +5 至出院）、婚事要钱 +25、父母住院 +20、房贷断供 +30、催婚 +5。每日自然衰减 −3。

效果：拒绝药代的说服检定 DC + ⌊现金压力/20⌋；接受药代的 SAN 代价 ×(1 − 现金压力/200)；现金压力 ≥60 时药代事件出现概率 ×2。

## 5. 隐患（隐藏）

四类，按病人聚合，鉴定庭逐条读出。

| 类 | 内容 | 典型权重 |
|---|---|---|
| R 规范 | 该查未查、该会诊未会诊、该转诊未转诊、用药禁忌、未测血糖、未做心电图 | 10／15／25／30（按规范明文程度与因果关系） |
| D 病历 | 未记录、迟记、缺签字、篡改 | 5／10／12／篡改 +20 |
| C 沟通 | 未告知风险、未签拒绝检查记录、隐瞒坏消息、对家属失控 | 10／15／20 |
| F 费用 | 过度检查、特殊使用级抗菌药无审批、串换、超适应症 | 5／8／20 |

标记：`explicit_norm`（有明文规范可引）、`causal`（在因果链上）。鉴定庭只对种子病人的 R/C/D 计责任分值；F 走行政族。

夜班时间预算耗尽后的突发：每起 R +25（响应延误）。加班放弃病人：R +10、D +10。

### 5.1 审查值 Q：每次失误都会留下旧账

`Q` 是全局隐藏值，开局为 0。它不代替 R／C／D／F，只记录这一局留下过多少个可被追查的入口。

- 每次提交带 R／C／D／F 隐患或指定风险 flag 的选项：Q +1；其中任一隐患带 `causal`：再 +1；选项涉及隐瞒、篡改、销毁记录、统方或回扣：再 +2。一次选项的加值可叠加；同一选项的多条 `causal` 只加一次。
- 天然 1 额外生成隐患时，Q +1。一个选项产生多条同源隐患时只计算一次基础 +1，防止拆字段重复计分。
- 及时补救可降低患者结局严重度，并设置 `mitigated`；已经增加的 Q 与已经发生的行为不撤销。鉴定庭会同时读出失误和补救。
- 与投诉、复诊、病历抽查、飞检、同事追问有关的事件权重乘以 `min(2.0, 1 + 0.08Q)`。Q 达到 3／6／9 时，事件导演分别安排一次轻／中／重的旧账回响，在之后 1–3 天触发；若剩余回合不足，排进鉴定前夜或鉴定庭证据揭示。
- 若第十四天没有 S=2／3 的临床种子，仍掷一次抽卷 d20；`d20 ≤ min(18, Q)` 时，从有隐患的病例中按隐患总权重抽一例成为「复核种子」。复核种子本身不能凭空满足刑事伤害条件，但可进入行政、职业、关系或已有廉洁 flag 的结算。
- Q 进入鉴定庭立案 DC，详见 06。一次不经意失误即会改变之后的事件与结局概率；单个轻微失误不会脱离因果链直接判刑。

玩家游玩中不显示 Q，也不立即标注某项为「错误」。选项提交后立刻写入单局存档，不提供游戏内撤销；结局揭示时才显示完整账本。

## 8. 日终检定与 debuff 三选一

- 掷 d20 + 抗压修正 vs 当日 DC。
- 抗压修正 = 天赋（0–3）+ 家人关系（0–2，关系 ≥4 给 +2，≥3 给 +1）− 抑郁档（1／2／3）− 负债档（负债 >¥10,000 −1，>¥30,000 −2）− 加班标记（当日加班 −1）。
- 失败：从 debuff 池按当前状态加权抽 3，玩家必选 1。天然 1：抽 3 选 2。天然 20：移除一个现有 debuff。
- 成功：无事；连续三日成功 → 情绪 +5。
- debuff 池与解除条件见 02。

## 9. 掷骰检定

- 只掷：问诊（让人说实话）、察觉（看出体征与细节）、安抚（家属、医闹、拒检）、文书（补记不漏、抗鉴定）、说服（主任会诊、稽核员、同事）、抗压（日终、目睹造假、被骂）。
- 公式：`d20 + 技能(0–5) + 情境修正 vs DC`。
- 情境修正一览（面板逐条显示）：

| 来源 | 修正 |
|---|---|
| 体力 <50／<30 | −1／−2 |
| SAN <50（失真或崩坏） | 安抚、说服检定 −2；与 §2.2 一致，不另叠加崩坏 −3 |
| 情绪 <30 | 安抚检定 −1；说服不受此项扣减，与 §2.3 一致 |
| 加班状态 | −1 |
| 关系 ≥4／≤1 | 优势／劣势（对应 NPC） |
| 踩坑档案命中 | +2 |
| 家属在场（问诊患者隐私） | −2；请家属离开后消失 |
| 天赋 | 各自 |
| 现金压力 | 拒绝药代 DC +⌊压力/20⌋ |

- 优势／劣势：掷两颗取高／低；同时存在则抵消。
- 天然 20：成功并额外揭示一条隐藏事实；天然 1：失败并附一条隐患（问诊／察觉 → R +5；安抚 → C +10；文书 → D +10）或 SAN −5（抗压）。
- DC 表：容易 9、普通 11–12、困难 14、很难 16、几乎不可能 19。病例预设按压迫曲线 ±。
- 不掷骰的地方：查体项目、化验选择、影像、用药、会诊时机、转诊时机——这些是确定的正确／中性／陷阱。
- 面板文本（系统档）：「问诊检定 · d20 + 问诊 2 − 家属在场 2 · DC 13」→「掷出 15 · 合计 15 · 成功」→「他说他每天喝半斤。」

## 10. 组合生成：每局不一样

三层组合，外加事件库。

```
门诊病人 = 患者实体(11) × 病例预设(12) × 变体修饰 × 环境片段
```

- **患者实体**（≥200）：年龄段、性别、职业、性格、陪同者、支付能力、隐瞒倾向、台词风格、对录音／投诉的倾向。字段见 11。
- **病例预设**（≥200）：诊断、呈现、底牌、步骤骨架、关键陷阱与对应规范、DIP 病组与预算、正确路径耗时、兼容约束（年龄、性别、科室、时段）。字段见 12。
- **变体修饰**（每次抽 0–2 个）：隐瞒项替换、陪同者更换（无人陪／多人陪／录音者）、支付方式（医保／自费／欠费）、时段（门诊尾号／夜班末段）、语言障碍、认知障碍。
- **环境片段**：按（阶段 × 时段 × 疲劳档 × SAN 档）从片段库抽一条。

匹配规则：预设的 `constraints` 与实体的 `tags` 求交集；不满足则重抽；同一实体一局内最多出现 2 次（第二次作为「复诊／再入院」）；同一预设一局内不重复；底牌比例按当日曲线抽取；每局至少 1 个儿科、1 个老年、1 个孕产相关预设。

事件（≥200）分七类：床旁、交班、日终、家庭、药代、医保／DIP、科室政治，每类有触发条件与权重，按压迫曲线与状态加权抽取，同一事件一局不重复。

### 10.1 蝴蝶效应：跨线传播

蝴蝶效应使用已有资源、人物记忆、承诺与证据状态，不新增数值条。Q 只表示审查风险；普通帮助、拒绝和中性选择均可产生跨线影响而不增加 Q。共同字段见 `15_蝴蝶效应与因果链.md`，分支正文、人物与交叉场景见 `16_暗黑事件链/`。

| 全局规则 | 数值或边界 |
|---|---|
| 每局有机会启动的跨线入口 | 4–6 个【假设】；不是强制触发的灾难数；前提不足不补造事件 |
| 跨线目标 | 主要链跨至少 2 个系统；至少一条可延伸至第三个系统【验收目标】 |
| 首次跨日后效 | 1–3 天【假设】，在入队时固定 |
| 后续传播间隔 | 1–4 天【假设】；病例当下处置仍用本身分钟规则 |
| 一次事实的直接后继 | 最多 2 条【假设】；更多影响合并成同一幕的多个条件 |
| 一条分支的自动传播 | 最多 4 次【假设】；到上限收束或转为明确的新选择，不递归刷事件 |
| 出场预算 | 占用 §7 的回响槽；替换普通随机槽，不能在原配额外叠加 |
| 有利或混合路径 | 每条主要链至少一条，并有一个中途可改向的节点；不可逆后果仍按本身规则成立 |
| 人情调用 | 必须绑定提供帮助的 NPC、其在岗状态与已完成的帮忙；每份未兑现承诺只能用一次；请求完成交接消耗 1 AP【假设】，可覆盖的职责由对应事件声明 |

每个派生结果都记录直接来源；从同一来源重放或展示已发生的后果，不重复结算。新的失误照 §5 记隐患和 Q，不能因为一条因果链有多条边就重复惩罚入口。

同一天先提交选择与即时结果，再按阶段末的状态快照安排后效；跨日边不会在同一轮调度里继续触发下一条边。所有待办到达期限时必须兑现、中断、失效或进入尾声；尾声不伪造未发生的临床伤害。

上述间隔约束条件已经满足后的排期，不提前制造尚未发生的家庭事故或项目。暂时没有出场条件但仍有有效承诺的链可以休眠；休眠不是到期待办，不占配额。明确退出、目标离场、项目终止与局末才提交最终收口，普通平静期只记录候选尾声。

基准压力逐日上升，但聪明的资源安排与有利连锁可以造成局部喘息。导演不追踪玩家是否占到便宜再追加坏事。永久成长只继承 §11 的内容，不继承上一局的因果链状态。

复杂度来自条件解法、执行者、知情范围与可达收口，不增加每回合的点击配额。无选择自动传播的上限不限制整条有新决策的剧情总长度；每个决策节点仍占原回响/事件配额。替代入口不补演错过的节点，未走分支不计作本局待办。

应收款、待处理转入款、信用贷款和私人应付款分账。单方转入且尚未同意使用的款项不可支出，不生成接受利益交换的事实；退回失败保留待处理状态。私人应付款按该笔明确约定计息/到期，不默认套用信用贷款的回合利息；所有同日出账均检查最新可用余额。项目经费不等于个人余额。

人物的承诺、立场与知情是状态，不再加关系数值条；需要数值代价时只用 §3 的既有关系类别。省掉一次动作表示该动作成本为零，不凭空返还 AP。项目文书/科研隐患须标记项目范围，不挂到任意患者身上；一般知情或未核来源不生成“明知造假”事实。
