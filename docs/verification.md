# 验证范围

## 自动检查

- Vitest 覆盖状态机、不可重复提交、独立随机键、重载确定性、日终与归零分支、预算退款、借贷利息、家属求助次数、提前出院同人回院、科研/临床作用域隔离、多周目奖励与上限。
- 地图与患者检查覆盖房间布局、路径可达性、床位容量、患者床号、满床留观和住院状态；带教检查覆盖真实事件推进、非检定跳过骰子、跳过与重开、重复事件以及持久化数据校验。
- 内容检查覆盖 20 例、80 个临床阶段、35 个手写节点、345 个手写选项、12 项天赋、24 项负面状态、前置节点、循环依赖、选择路径、标签长度与原创性禁用词。
- 四种模拟策略检查整局能结束、资源不出现 NaN、重复选择不重复收费、结局可到达。模拟策略可读内部内容，输出不能当作真实玩家胜率。
- TypeScript 和 Vite 生产构建；所有本地图片随构建产物交付；运行时无字体服务、追踪脚本或 API 密钥。
- GitHub Actions 在 `main` 推送后执行测试、内容校验和生产构建，通过后发布到 GitHub Pages；每次执行结果可在仓库 Actions 中查看。

## 浏览器检查

已在浏览器中检查以下视口的天赋选择、床旁患者、病历分页和掷骰界面：

| 视口 | 布局 |
| --- | --- |
| 1280 × 800 | 桌面 |
| 390 × 844 | 竖屏 |
| 844 × 390 | 横屏 |

这些是浏览器视口测试，不是实体手机验收。骰子支持拖动松手、点击与键盘回车；处置与日终结果由同一状态机一次结算，演出不生成新的骰面。已实测处置后走到 C 病房、刷新并继续值班，位置、行动、体力和带教进度保持一致，没有重复收费。WebGL 降级路径尚未完成浏览器实测，自动测试中的确定性覆盖不替代端到端检查。

## 边界

这是静态单机叙事游戏，不是临床训练、法律推演或医保政策模拟器。其预算、利息、调查与判决规则不能用于现实决策。

触屏布局包含纵向、低高度横向、大字号与减少动态效果规则。浏览器验收范围限于上表；实体手机触控、不同浏览器和长时间游玩仍需另行检查。

WebMCP 是可选浏览器提案。缺少支持该接口的浏览器验证环境时，不宣称其注册与端到端调用已验收；普通网页游玩不依赖它。

全量设计资料里的其他病例预设和长篇事件没有伪装成已进入运行版。发布内容数量以当前内容检查输出为准。新增内容需遵守作用域、知情时间、实际兑现和玩家文案边界。

配音模型的离线接入写在 `audio.md`；当前游戏声音是可选提示音，不宣称已经有角色全对白配音。
