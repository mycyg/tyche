# 预设中段文案与证据范围

## 核查口径

固定范围为 208 个预设中段的 1,248 个场景、4,485 个选项，其中 442 项带成功/失败检定。首步另有独立报告。本报告中的场景和选项计数不包含实体需要、重遇等实例附加节点；这些节点的人称仍作为角色核查对象。

事实依据是预设的 `presentation`、`hidden`、`pathway`、`traps` 和对应设计文件。玩家所见须服从实际选项范围；同一段来源中的多个事实不意味着任何一个动作都能得到全部事实。

说话人分别为医生、实际患者、原文指定的陪同者、原接诊人及检查回报者。家属陈述不改成患者承认，查阅药盒不改成问到用药经过，检查发现不改成已经治疗。原有费用、时间、行动、难度、事实标记及分支不属于本次文字修订范围。
