# 独立浏览器试玩记录

## 证据范围

这份记录来自独立代理实际操作浏览器的路径，不是主代理亲自试玩的记录，也不是引擎模拟。页面使用本仓库构建产物，隔离地址为 `http://127.0.0.1:5177/tyche/`，Chrome 标签页为 `1243094047`；未操作主代理的标签页 6、4173 存档或部署站点。

操作依据限于当前页面的文案与可见成本。未修改资源、属性、标记、患者伤害或结局，未读隐藏风险作为选项策略。地图目的地、床旁、处方确认、骰子和结局均实际打开检查。重复操作通过同一浏览器的无障碍按钮与可见文字完成，逐步重新读取界面。

第一天曾在隔离本地响应中临时提供 `document.modelContext.registerTool` 收集器，仅接收应用自行注册的三个公开接口。它处理了四位患者的“维持医嘱，暂不床旁复核”选择及继续操作，没有调用私有引擎或注入存档；此后收集器已移除，服务器恢复原版预览，正常刷新同一存档，余下流程均为实际 UI 操作。这段不计作浏览器原生 WebMCP 能力，也不描述为全程鼠标操作。
