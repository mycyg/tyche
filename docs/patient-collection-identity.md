# 患者图鉴的身份与收录

患者分类共有 271 份独立档案：日常患者实体库 251 人（原有 222 人、扩展 29 人），以及重点病例的 20 位固定登记患者。两组没有共用的身份 ID，也不按姓名相似、年龄相同或疾病相同合并。

## 来源

- 日常患者：设计文档 `11_患者实体库`；运行资料为 `src/content/patients/entities.json`，身份 ID 为 `P-001` 至 `P-251`。P-251 是由母亲陪同的 7 岁儿童，只匹配 C-151 的年龄适用分支，不改变原有儿童的年龄。
- 重点病例固定患者：`patient-presence-a.json`、`patient-presence-b.json` 提供当前游戏的固定姓名；设计文档 `04_病例库` 的对应病例呈现提供年龄、性别与接诊资料。登记索引为 `src/content/clinical/patient-identities.ts`，ID 为 `CP-C001` 至 `CP-C020`。
- C019 以 39 岁孕妇许宁为主档，同次接诊的丈夫、女儿列在其资料中，不把一份主档算成三份独立收藏。

## 身份确认

日常实体按真实 `entityId` 收录。固定患者必须同时符合对应病例 ID 和固定姓名，且不能带有其他日常实体 ID 或病例预设身份。

同一重点病例再次出现时，患者可能获得另一个姓名。这是不同的人：本次接诊会记录在其自己的病历和病例收藏中，不解锁未接触的固定患者。床位生成、候诊排队、原班完成治疗，也不等于玩家已经接触。

接触证据包括实际走到患者身边、患者范围内已提交的临床或问诊操作，以及已经执行的图谱选择。收藏只在轮转结算后写入成长档案。

## 存档

`Meta.entities` 保留日常实体身份；`Meta.clinicalPatients` 保存独立的固定患者身份。读取时分别按对应白名单校验，拒绝重复或非法 ID。

旧存档只有 `meta.cases` 时，无法确定此前见过的具体姓名，不据此推定固定患者。若存档仍保留已结算并已发放成长奖励的原轮转，且原患者与接触证据均在，则恢复对应姓名的收藏。恢复不再次发放经验、悟性或金钱，不修改医疗选择、费用、骰子或病历。

图鉴公开姓名、年龄、性别、科室和接诊时主诉；隐藏病史、检查结果及未来结局不属于身份收藏资料。
