# Tyche

十四天轮转。第十五天，鉴定庭。

一款可以在医院里行走的中文 2D 像素 JRPG，结合暗黑医疗叙事与 roguelike 轮转。走进病房，查看床头病历，决定怎么处置，再亲手掷下骰子。每天都是一个回合：接诊、查房、沟通、付账、交班。你可以预支明天，也可以借钱继续撑。前面的选择不会消失，后面的人会带着自己的录音、账单和记忆回来。

## 这份值班表

- 20 份四阶段病例、35 个手写剧情节点、6 类短事件、4 类夜间急诊；病例、顺序与检定由轮转码决定。
- 四条跨日支线：同事顶班、私人借款、家属录音、科研项目。角色援手、材料签收、资金往来与知情时间分别留痕。
- 每日行动值、预支和透支；SAN、体力、情绪有不同的归零后果。
- 1536 × 512 的可行走医院，12 个房间，A、B、C 三间病房共 12 张住院床。床位与真实患者状态对应，满床患者进入留观；患者住院天数、出院条件、家属耐心、病组费用和超期审核持续保留。风险未排除的提前出院可能造成严重恶化回院，并触发录音、举报和个案责任调查。
- 床旁患者画像和四页病历夹：入院登记、问诊与检查、处置与交班、费用。未取得的信息不会被当作已完成检查；病组预算、累计诊疗费和医生垫付分开显示。
- d20 接诊、沟通、医保申诉、日终与立案检定；天然 1 与天然 20；24 项负面状态。
- 12 项带代价的天赋，23 种主结局，多条可叠加支线去向；经验可提升六项技能、三项上限和初始积蓄。
- 2D 像素人物与六位原创角色立绘。鼠标点地行走、键盘移动、触屏摇杆；支持横竖屏布局、减少动态效果与可选合成提示音。
- 护士带教从走近病床开始，按实际操作记录进度；可跳过、在设置重开，随时查阅天赋解释和术语手册。
- 自动保存、上一份存档备份、导入导出、结局分享。无账号、无分析埋点、无后台模型调用。

所有人物、机构、制度、病例、预算、利率与判决均为虚构的游戏内容，不构成医疗、法律或财务建议。包含医疗事故、精神困扰、债务和刑事判决主题。

## 游玩

锁定三项天赋，接过胸牌。用 `WASD`、方向键或左下摇杆移动，也可以点击地面或目的地行走。靠近病床和人物后按 `E`、空格或点「交互」。床旁可以翻开病历，`J` 也能打开病历夹。

先看清选项的行动消耗、诊疗记账与个人自付，再确认处置；键盘 `1`—`4` 可选中当前选项。处置检定和日终骰子可以拖动松手、点击，或聚焦后按回车投掷。动画展示已确定的结果，拖动方向不会改变骰面，也不会重复结算。没有检定的选择直接给出结果。`Esc` 关闭可返回的窗口，没有现实时间倒计时，可以停下来读。

存档位于当前浏览器。换设备或清理网站数据前，请在「设置与存档」中导出。刷新不会重掷已确定的骰子。成长与天赋不同，即使轮转码相同，结果也可能不同。

## 本地运行

需要 Node.js 22.12 或以上版本。

```sh
npm ci
npm run dev
```

打开终端打印的 `/tyche/` 地址。

```sh
npm test
npm run check:content
npm run simulate -- 100
npm run build
npm run preview
```

`simulate` 使用随机、风险规避、成长后风险规避、鲁莽四种策略。策略能读取内容数据，是回归测试工具，不是玩家胜率估计。
